# TA Handover Checklist

A safe, self-contained walkthrough of the GitHub contribution workflow. Practice every step here before touching real project work.

## Practice steps

- [ ] **Create a branch** — branch off the default branch (`main`) so your changes stay isolated, e.g. `practice/first-change`
- [ ] **Open a pull request** — from your practice branch into `main`, with a clear title and a short description of what changed
- [ ] **Review the changes** — read the diff, leave an inline comment on a specific line, and submit the review (comment, approve, or request changes)

## Notes

- Nothing in this repository is production code — it exists purely for practice.
- Repeat the flow as many times as you like; it is the same flow you will use on the real repositories.
